# Human Detection & Counting with YOLOv5

Real-time people-detection and crowd-counting pipeline built on **[YOLOv5](https://github.com/ultralytics/yolov5)** (PyTorch).  
Suitable for CCTV footage, retail analytics, smart-city monitoring, and any application where knowing **how many people are present** matters.

---

## ✨ Key Features
| Feature | Notes |
|---------|-------|
| **Pre-trained** | Uses COCO-trained `yolov5s` model . |
| **Real-time FPS** | Runs ≥30 FPS on a modern GPU (`yolov5s` @640×640 on RTX 3060). |
| **Simple people-counter** | Counts unique detections per frame.|
